# Fonts for the business card

Geist and Geist Mono, the interface fonts, for `app/branding/card.py`: the
weights the card uses, with Latin, Latin Extended and Cyrillic, built from the
`@fontsource/geist` and `@fontsource/geist-mono` packages the frontend installs
by `tools/make_card_fonts.py` (WOFF subsets merged into TrueType, which the PDF
can embed). Licensed under the SIL Open Font License 1.1 (`OFL.txt`).
