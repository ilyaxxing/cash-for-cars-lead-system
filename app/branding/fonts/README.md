# Fonts for the business card

Geist and Geist Mono, the interface fonts, and Sofia Sans Extra Condensed, the
display face, for `app/branding/card.py`: the weights the card uses, with
Latin, Latin Extended and Cyrillic, built from the `@fontsource/geist`,
`@fontsource/geist-mono` and `@fontsource/sofia-sans-extra-condensed` packages
the frontend installs by `tools/make_card_fonts.py` (WOFF subsets merged into
TrueType, which the PDF can embed). Licensed under the SIL Open Font License
1.1 (`OFL.txt` for Geist, `OFL-SofiaSans.txt` for Sofia Sans).
